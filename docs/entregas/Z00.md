# Z00 Base local

Objetivo: web mínima, Supabase local y diagnóstico reproducible. No incluye tablas de producto ni autenticación de usuario final; pertenecen a zonas posteriores.

Criterios: instalación reproducible con Node 24.22.1 y lockfile; Docker y base accesibles; compilación y lint; secretos no versionados; esquema API vacío y privado no expuesto; sin reset automático.

## Inicio en Windows

Abrir Docker Desktop y esperar a que el motor esté activo. Instalar Node 24.22.1 o seleccionar el runtime Node 24 indicado en docs/versions.md. En PowerShell desde app:

```powershell
npm ci
npx --no-install supabase start
npm run doctor
npm run dev
```

Abrir http://localhost:3000. Supabase Studio: http://127.0.0.1:54323. Para pruebas de build: npm run build, npm run lint y npm run typecheck. No ejecutar db reset sobre datos que se quieran conservar. La primera descarga de imágenes necesita internet.

La pantalla de inicio es únicamente una señal de base; no contiene el feed ni representa funcionalidades ya terminadas.

## Runtime disponible en este equipo

El Node del sistema es 20.20.2. Está disponible Node 24.22.1 dentro del runtime de Codex. Para usarlo sin cambiar la instalación global, desde app en PowerShell:

    $RiuyaNodeBin = 'C:\Users\LINKX7\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin'
    $env:Path = "$RiuyaNodeBin;$env:Path"
    & "$RiuyaNodeBin\node.exe" node_modules/next/dist/bin/next dev -H 127.0.0.1

Para diagnóstico:

    & "$RiuyaNodeBin\node.exe" scripts/doctor.mjs

Cuando Node 24.22.1 esté instalado y seleccionado en el sistema, sirven los comandos npm indicados arriba. No instalar ni cambiar Node global automáticamente.
