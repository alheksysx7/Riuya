# Z02 Publicación editorial manual — en desarrollo

Alcance: crear, revisar, aprobar y publicar una noticia de ocho opiniones, además de retirarla. Z01 aprobada por el usuario con «siguiente paso».

Se preparó un borrador SQL de tablas, revisiones, fuentes, opiniones y eventos; fue validado en una transacción con ROLLBACK y no está aplicado como migración. Las tablas privadas no se conceden directamente a los roles cliente.

Pendiente: funciones transaccionales con autenticación y autorización editorial, control de versión y aprobación, prueba de 7/9 opiniones y retirada, panel manual seguro, pruebas de integración y entrega reproducible. La pantalla de acceso editorial requiere una solución segura para esta zona anterior al login de lector Z04. No se considera lista para revisión ni se debe iniciar Z03.
